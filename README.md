# 📂 Smart File Organizer

A professional desktop tool developed to help users declutter their folders in seconds. This app automatically detects file types (like .exe, .pkg, .iso, .apk, .json, etc.) and moves them into dedicated folders.

## 🚀 Features
* **Custom Organization:** Input specific extensions you want to sort.
* **Smart "All" Mode:** Organize every file in the folder with one click.
* **Modern GUI:** A sleek dark-mode interface built with `CustomTkinter`.
* **Standalone EXE:** Works on Windows without needing to install Python.

## 🛠️ Built With
* **Language:** Python
* **GUI Library:** CustomTkinter
* **Bundler:** PyInstaller

## 📖 How to Use
1. Select the folder you want to clean up.
2. Enter the extensions separated by commas (e.g., `apk, pkg, exe`).
3. Or simply click **"All"** to organize everything.
4. Watch your files get sorted instantly into named folders!
